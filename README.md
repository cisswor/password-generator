# Password Generator

A clean, feature-rich password generator built with HTML, CSS and JavaScript.

## Features

- Random and pronounceable password modes
- Strength presets — Regular, Medium, Strong
- Adjustable password length
- Toggle uppercase, lowercase, numbers and symbols
- Exclude similar characters (0, O, l, 1, I)
- Strength indicator with improvement tips
- Crack time estimator
- Password history — last 5 generated passwords
- Dark and light mode
- Copy to clipboard
